Controles (teclado / mando):
  Flechas / cruceta o stick   menús: mover el cursor / juego: dirección de la nave
  Z, Enter / A                aceptar / disparar (dos balas: delante y detrás)
  X / B                       volver / activar el escudo
  P, Esc / Start              pausa
  F2            mostrar las hitboxes
  E / Back      editor de niveles (Z base, X borrar, R girar, S inicio, O menú)
  T             modo trampa: invencible; N siguiente ronda, 1 alerta, 2 espía,
                3 formación, 4 carga de escudo

Ejecución local:
  pip install -r requirements.txt
  python main.py
